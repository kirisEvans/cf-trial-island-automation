# 试炼岛自动投卡工具

这是一个用于《穿越火线》试炼岛的本地辅助工具。启动后会打开一个控制台页面，你可以选择“无限循环投卡”或“自动攻击”。

> 请自行了解并遵守游戏规则及用户协议。本工具仅模拟本地键盘和鼠标操作，使用风险由使用者自行承担。

## 使用前准备

- 使用 Windows 10 或 Windows 11。
- 游戏界面建议使用 **1920 × 1080** 分辨率，且不要被其他窗口遮挡。
- 记住游戏在 Windows 任务栏中从左到右排第几个图标，例如第 4 个。

## 怎么启动

### 直接运行 Python 版本

首次使用，在项目文件夹打开 PowerShell，输入：

```powershell
python -m pip install -r requirements.txt
python boss_automation_v2.py
```

弹出管理员权限提示时请选择“是”。启动成功后，控制台页面会自动打开。

### 运行 EXE 版本

如果你已下载或打包了 EXE，打开：

```text
BossAutomation\BossAutomation.exe
```

请保留整个 `BossAutomation` 文件夹，不要只复制 `.exe` 文件。

## 怎么填写“任务栏位置”

任务栏位置就是游戏图标在 Windows 任务栏从左到右的顺序，范围为 1～9。

例如游戏图标排在第 4 个，就在工具中填写：

```text
4
```

位置填写错误时，工具会切换到错误的程序。

## 功能一：无限循环投卡

1. 打开控制台中的 **卡片投放** 页面。
2. 选择需要使用的卡片星级和卡片序号。
3. 填写游戏的任务栏位置。
4. 点击 **开始无限循环投卡**。

工具会不断执行：按一次 `E`、选择卡片、点击“召唤 Boss”，然后立即重复下一轮。它不会识别怪物状态，也不会自动打怪。

### 如何停止投卡

你可以使用任意一种方式：

- 点击右上角的 **停止当前任务**。
- 按键盘 **空格键**。

如果需要更换卡片星级、卡片序号或任务栏位置，修改后直接再次点击启动，旧任务会自动停止并按新设置开始。

## 功能二：自动攻击

1. 打开控制台中的 **自动攻击** 页面。
2. 填写游戏的任务栏位置。
3. 点击 **启动自动攻击**。

工具会切换到游戏，持续按住鼠标左键，并且每 10 秒按一次 `F` 键。

### 如何停止自动攻击

点击右上角的 **停止当前任务**，工具会停止按键并松开鼠标左键。

## 更换控制台背景

在卡片投放页面点击 **选择本地图片**，可选择 JPG、PNG 或 WebP 图片作为背景。点击 **恢复默认** 可换回原始背景。

## 常见问题

### 控制台显示“未连接”

请先启动 `boss_automation_v2.py` 或 `BossAutomation.exe`，再点击控制台里的启动按钮。

### 工具没有切换到游戏

检查任务栏位置是否正确。任务栏固定图标、其他打开的程序或顺序变化都会影响位置。

### 卡片或按钮点击错位

请检查游戏分辨率、Windows 缩放比例和游戏界面布局。当前坐标按 1920 × 1080 设计。

## 想自己打包成 EXE（可选）

只有想生成 EXE 文件时才需要这一步。先执行：

```powershell
python -m pip install pyinstaller
```

然后在项目文件夹执行：

```powershell
python -m PyInstaller --noconfirm --clean --onedir --windowed --name BossAutomation --add-data "card_control_panel.html;." --add-data "card-wallpaper.png;." boss_automation_v2.py
```

打包完成后的程序在：

```text
dist\BossAutomation\BossAutomation.exe
```
